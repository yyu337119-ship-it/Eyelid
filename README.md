# 系统评价小鼠眼睑异常表型

按解剖部位整理小鼠眼睑/眼表异常的系统评价路径：

1. **MG 及其分泌物**
2. **角膜和泪膜、泪液**
3. **结膜**
4. **眼睑相关肌肉**

每个检测分支写出检测手段/仪器、分子标志物、观察结果、原文图表。
