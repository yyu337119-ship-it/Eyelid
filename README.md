# 系统评价小鼠眼睑异常表型

按解剖部位整理小鼠眼睑/眼表异常的系统评价路径，把笔记 PDF 里分散的条目收成四个问题：

1. **MG 及其分泌物**
2. **角膜和泪膜、泪液**
3. **结膜**
4. **眼睑相关肌肉**

每个小分支都固定写出：**检测手段/仪器、分子标志物、观察结果、原文图表**。

## 颜色与文献

| 颜色 | 文献 |
| --- | --- |
| 红字 | [2] Widjaja-Adhi MAK, et al. *IOVS* 2026; 67(6):34. [DOI](https://doi.org/10.1167/iovs.67.6.34) |
| 黄字 | [5] Dong F, et al. *Developmental Biology* 2015; 406(2):147–157. [DOI](https://doi.org/10.1016/j.ydbio.2015.09.003) |

[2] 的图来自笔记 PDF 中已复制的原文图，图注按归纳文字重写。[5] 的图在笔记中多半未贴图，页面保留图号、读图要点，并链到 PMC 开放获取原文。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43127](http://127.0.0.1:43127)。

```bash
npm run build
npm start
```

## 使用方式

- 左侧目录按四大分类跳转。
- 顶部可按红字 [2] / 黄字 [5] 筛选。
- 点击有图的卡片可放大原文图。
- 标记为「笔记待补」的条目（睑脂熔点/组分、TBUT/NIBUT、结膜充血与黏蛋白）保留了问题，方便后续补原文方法。

若要继续补全 [5] 的原图或 [2] 未贴图的方法学细节，把原文 PDF 放到对话里即可。
